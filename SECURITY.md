# Security Policy

## Báo cáo lỗ hổng

Vui lòng **không** mở issue công khai cho lỗi bảo mật.

Báo qua GitHub Security Advisories: <https://github.com/jhin1m/smm-panel/security/advisories/new> ("Report a vulnerability").

Hãy kèm: phiên bản (tag release hoặc file `VERSION` trong image), các bước tái hiện, tác động dự kiến. Chúng tôi sẽ phản hồi sớm nhất có thể và công bố bản vá cùng advisory sau khi người dùng có thời gian cập nhật.

## Phiên bản được hỗ trợ

Chỉ bản phát hành ổn định mới nhất (`latest`) nhận bản vá bảo mật.
